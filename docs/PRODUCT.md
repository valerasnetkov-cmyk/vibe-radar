# Product — Vibe Radar

## 1. Mission

Help developers, AI builders, indie creators, freelancers, and small studios discover noteworthy open-source projects early, understand why they matter, and track how they evolve.

## 2. Positioning

Vibe Radar is not a generic technology news feed and not a mirror of GitHub Trending.

Its differentiation is:

1. longitudinal repository snapshots;
2. growth velocity and acceleration;
3. transparent VIBE SCORE;
4. editorial relevance to vibe coding / AI development;
5. repeatable project history;
6. structured multi-channel publishing;
7. later personalized watchlists and alerts.

## 3. Primary audiences

- vibe coders / AI-enabled builders;
- indie hackers and small SaaS teams;
- frontend/backend developers;
- freelancers and small studios;
- users of coding agents and MCP tooling;
- self-hosting and automation enthusiasts.

## 4. Initial editorial themes

- Coding Agents
- MCP
- AI developer tools
- automation
- self-hosted software
- web/SaaS tooling
- developer infrastructure
- UI/dev experience
- cybersecurity tools relevant to builders

## 5. Editorial formats

- `Trending` — fast growth now;
- `Fresh` — young repositories with unusual traction;
- `Release` — meaningful new version;
- `Hidden Gem` — strong quality/relevance with modest star count;
- `Watch` — follow-up on a previously discovered project;
- `Comparison` — later, factual comparison of alternatives;
- `Vibe Review` — later, community-submitted projects with permission;
- `OUTSCAN Check` — later, approved deployment/security content.

## 6. MVP user outcome

A reader should consistently receive a small number of high-signal projects with clear answers to:

- What is it?
- Why is it interesting now?
- Who is it for?
- How fast is it growing?
- What is the practical use?
- What are the important limitations?

## 7. Non-goals for MVP

- automatically running code from discovered repositories;
- ranking projects based on sponsorship/ads;
- autonomous publishing without trusted editorial approval;
- security assessment of arbitrary third-party targets;
- personalized user accounts;
- a full social network/community platform.

## 8. Product principles

- Signal over volume.
- Explainable ranking over opaque hype.
- Longitudinal data over one-time snapshots.
- Human editorial control over autonomous publishing.
- Native monetization/integration must not contaminate editorial ranking.
